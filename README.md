# ⚛️ Quantum Playground

An interactive quantum energy-level simulator that demonstrates electron transitions and photon absorption and emission in a hydrogen atom.

## ✨ Features

- Visualizes three hydrogen energy levels.
- Animates electron transitions between energy levels.
- Allows users to control transitions using keyboard controls and on-screen buttons.
- Explores photon energy and energy differences between levels.
- Demonstrates photon absorption and emission.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- [p5.js](https://p5js.org/)
